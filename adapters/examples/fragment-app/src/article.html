HTML inside your application

This window uses html-gpui directly. The application supplies the window and scroll container; the element lays out ordinary HTML and CSS.

Selection and copying

Drag to select text, double-click a word, or triple-click a paragraph. Use the platform copy shortcut to copy your selection.

Text can contain Unicode: café, Ελληνικά, 日本語, and emoji 👩‍💻.

Layout belongs to the host

Resize this window to reflow the paragraphs. Scroll to see the rest of the document. This application has no reader session, page count, or column settings.

  • Use this element for descriptions, help panels, and document previews.
  • Supply CSS to control typography, spacing, and colors.
  • Enable selection independently for each element.

Custom document surfaces

Applications that manage their own document layout can use the adapter's public shaping and painting backend with the framework-independent HTML engine.

The reader adapter builds on the same backend when an application needs publication navigation and pagination.
