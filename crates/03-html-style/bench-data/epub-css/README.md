# EPUB CSS benchmark corpus

These stylesheet-only fixtures were extracted from five EPUBs in the local
Syncthing book collection. They represent a small classic, a conventional
trade book, a code-heavy technical book, a visually oriented book, and a large
illustrated reference work.

Only CSS assets are retained: the corpus contains no book prose, metadata,
fonts, or images. Filenames describe the production shape rather than the
source title. Rights in the original stylesheets remain with their respective
owners; these copies are used solely as performance fixtures.

The numbered files are consumed by `examples/epub_css_benchmark.rs`.
